# 지금까지 만든 것과 설계 결정

탭 5개와 화면 전체에 걸친 기능이 있다. 괄호 안은 관련 커밋이다.
"왜"가 적힌 항목은 사용자가 직접 요청했거나 함께 정한 것이니, 바꿀 때는 먼저 사용자와 이야기한다.

## 화면 전체

- **포켓몬 사진 켜기/끄기** (13f19b7): 헤더의 스위치로 바꾼다. 끄면 사진 자리에 도감 번호가 나오고, 설정은 저장된다.
  - 사용자 요청이다. 끄면 사진 자리에 숫자를 보여 달라고 했고, 그 숫자는 도감 번호로 정했다.
- **포켓몬 정보 창** (c64a2f8, 29e3ace, 202882d): 어느 화면에서든 포켓몬 사진(또는 번호)을 누르면 창이 열린다.
  - 보여 주는 것: 타입, 스피드 종족값, 방어 상성(받는 피해 배율별 타입), 특성(이름, 설명, 숨겨진 특성 표시)
  - 브라우저 기본 `<dialog>`를 `showModal()`로 연다. 바깥 배경, Esc, ✕로 닫힌다.
  - 방어 상성은 타입만으로 계산한다. 특성 효과(예: 부유 → 땅 무효)는 반영하지 않고, 창 안에 그렇게 안내한다.
  - 검색 후보 목록 안의 사진은 누를 수 없다(`interactive={false}`). 후보 줄 전체가 버튼이라 버튼 안에 버튼이 생기는 것을 막기 위해서다.
- **포켓몬 검색** (`PokemonSearch`): 한글과 영어로 찾고, 입력하면 아래에 후보가 뜬다. 후보에는 종족값도 함께 보여 준다. Enter를 누르면 첫 번째 후보를 고르는데, 한글을 조합하는 중에 누른 Enter는 무시한다(`isComposing`).

## 순위표 (`SpeedTable`)

- 참전 포켓몬 전체를 최속 실수치 순으로 보여 준다. 보정이 없으면 스피드 종족값 순서와 같다. 열은 종족값과 최속, 준속, 무투자, 최저 실수치다.
- 이름 검색과 토글 3개(메가진화 표시, 스카프 ×1.5, 순풍 ×2)가 있다.
- **스카프는 메가진화 포켓몬에 적용하지 않고, 켠 상태의 최속 순으로 다시 정렬한다** (사용자 요청). 메가스톤을 지니면 스카프를 지닐 수 없기 때문이다. 스카프를 켜면 표 위에 이 안내가 한 줄 더 나온다.
  - 정렬 기준이 최속이라 스카프를 켜면 준속, 무투자 열은 위아래가 조금 어긋날 수 있다 ([speed-rules.md](speed-rules.md) 2절).
- 표 머리글은 화면을 내려도 위에 고정된다. 감싸는 요소에 `overflow: clip`을 써서 sticky가 페이지 스크롤을 기준으로 동작하게 했다.

## 1:1 비교 (`SpeedCompare`)

- 내 포켓몬과 상대 포켓몬을 하나씩 고르고(메가 포함), 양쪽마다 SP, 성격, 랭크(-6~+6), 스카프, 순풍, 마비를 정한다. 트릭룸도 켤 수 있다.
- 결과는 "한카리아스가 먼저 움직여요"처럼 보여 준다. 이름의 받침에 따라 이/가를 고르고, 같으면 "동속! … 랜덤(50%)"이라고 한다.
- 처음 값은 한카리아스 vs 드래펄트, 둘 다 최속이다. 이 탭의 설정은 저장하지 않는다.

## 내 파티 (`PartyEditor`)

- 최대 6마리이고, 같은 종(도감 번호)은 한 마리만 넣을 수 있다. 랭크배틀 규칙이며, 로토무 폼이나 켄타로스 종류도 같은 종으로 본다.
- 포켓몬마다 SP 슬라이더, 성격, 메가진화(그 포켓몬의 메가만 선택지로 나온다), 구애스카프를 정한다.
  - 메가를 고르면 스카프는 꺼지고 비활성이 된다. 메가스톤을 지니면 스카프를 지닐 수 없기 때문이다.
- 카드에는 "실수치 N (종족값 B) · 스카프 N · 메가 후 N (종족값 M)"을 보여 준다.
- 이 브라우저에만 저장된다. 휴대폰과 PC는 따로 저장된다.

## 매치업 (`Matchup`)

- 행은 내 파티, 열은 상대 포켓몬(최대 6마리)인 표다. 상대는 대전 전 팀 미리보기를 보면서 하나씩 입력한다.
- 칸 판정과 행·열 구성 규칙은 [speed-rules.md](speed-rules.md)의 5~6절에 있다.
- 사용자 요청으로 정한 것
  - **동속 표시** (2051b6e): "최속 동속"처럼 어느 투자와 동속인지 적는다. 처음에는 미러전에서 서로 최속인 경우가 "준속까지"로만 나와서 동속이라는 걸 알 수 없었다.
  - **종족값 함께 표시** (d20740f): 행, 열 머리글, 상대 칩에 "102족"처럼 종족값을 붙인다. 사람들이 종족값으로 이야기하기 때문이다.
  - **내 메가는 메가 모습만** (7e8a15e): 메가진화를 설정한 내 포켓몬은 메가 전 모습을 보여 주지 않는다.
  - **상대 스카프는 포켓몬별로 기억** (7e8a15e → cc47dec): 처음에는 표 전체에 스카프 켜기/끄기를 두고 모든 상대를 기본/스카프 두 칸으로 보여 줬다. 이후 사용자가 다시 포켓몬별 설정으로 바꿨다. 스카프를 쓰는 포켓몬은 대체로 정해져 있어서, 한 번 켜 두면 다음 대전에서도 그대로 쓰기 위해서다. 켜 둔 포켓몬만 기본/스카프 두 칸으로 나온다.
- 처음 만들 때 정한 것
  - **상대 메가 포함** (dd3ab88): "상대 메가 포함"(기본 켬)이 켜져 있으면 상대의 메가진화 모습도 칸을 따로 둔다. 상대가 메가스톤을 들었는지 미리 알 수 없기 때문이다.
- 내 파티가 비어 있으면 "내 파티 등록하기" 버튼으로 파티 탭으로 보낸다.
- 표가 화면보다 넓으면 가로로 스크롤되고, 내 포켓몬 열(왼쪽)은 고정된다.

## 상성표 (`TypeChart`)

- 18×18 표다. 세로가 공격 타입, 가로가 방어 타입이고, 칸에는 피해 배율을 적는다(빈칸은 1배).
- 타입 머리글을 누르면 그 줄이나 열만 강조하고, 아래에 배율별 타입 목록을 보여 준다.
- 600px 이하 폭에서는 타입 이름을 첫 글자로 줄이고 칸을 15px로 만든다. 375px 폭에 딱 맞춘 값이라 칸을 키우면 가로 스크롤이 생긴다.

## 저장 데이터 (localStorage)

형식은 `{ "version": n, "data": … }`이다. 읽을 때 parse 함수가 값을 검사해서, 지금 참전 목록에 없는 포켓몬이나 잘못된 값은 버린다.

| 키 | version | data |
|---|---|---|
| `champions-speed/party` | 1 | `PartyMember[]` = `{ key, sp, nature, scarf, mega }` (key는 진화 전 모습, mega는 메가 key 또는 null) |
| `champions-speed/opponents` | 2 | `{ key }[]` (v1에는 상대마다 scarf가 있었다. 읽을 때 버린다) |
| `champions-speed/scarf-users` | 1 | 스카프로 표시한 상대 포켓몬 key 목록 |
| `champions-speed/settings` | 1 | `{ showImages }` |

- 형식을 바꿀 때는 version을 올리고 parse에서 옛 version을 새 형식으로 바꿔 준다. `parseOpponents`가 그 예다.
- 키 접두어 `champions-speed/`는 바꾸지 않는다 (AGENTS.md의 주의할 점 참고).

## 스타일

- 색은 `src/index.css`의 CSS 변수로 정한다. `prefers-color-scheme`에 따라 라이트와 다크가 자동으로 바뀐다. 먼저/나중/동속 색은 `--win`, `--lose`, `--tie`(배경은 `-bg`)이다.
- 컴포넌트 스타일은 `src/App.css` 한 파일에 있다. 휴대폰 폭 규칙은 `@media (max-width: 600px)`에 둔다.

## 배포

- `main`에 push하면 `.github/workflows/deploy.yml`이 `npm ci` → `npm run build` → Pages 배포 순서로 실행한다. 저장소 Settings → Pages의 Source는 "GitHub Actions"여야 한다.
- 저장소 이름을 MySample에서 pokedex로 바꿨다 (0977fb0). 프로젝트 사이트 주소는 리디렉트되지 않아서 옛 주소(`/MySample/`)는 404다.
- GitHub Pages 한도는 사이트 1GB, 월 대역폭 100GB(soft limit)이다. 한 번 접속에 약 100KB(gzip)라서 여유가 크다.

## 알려진 한계

- 실제 게임의 4096 단위 보정을 쓰지 않아서, 보정이 겹치는 경계값에서 1 정도 차이가 날 수 있다.
- 1:1 비교 탭에서는 메가진화 포켓몬에도 스카프를 켤 수 있다. 순위표, 내 파티, 매치업은 메가에 스카프를 적용하지 않는다.
- 방어 상성에 특성이 반영되지 않는다 (부유, 저수, 타오르는불꽃 등).
- 종족값과 특성은 PokéAPI(본가 게임) 기준이다. 챔피언스만의 밸런스 변경은 반영되지 않는다.
- 탭이 주소에 반영되지 않는다. 새로고침하면 순위표로 돌아가고, 뒤로 가기와 탭 링크 공유가 안 된다.
- 이미지를 PokeAPI/sprites에서 핫링크하므로, 그쪽 경로가 바뀌면 이미지가 나오지 않는다.

## 다음에 할 만한 일 (제안만 하고 아직 하지 않은 것)

사용자가 고르기 전에는 시작하지 않는다.

- 탭을 `#matchup` 같은 `#` 주소에 연결하기. 새로고침, 뒤로 가기, 링크 공유가 되고 GitHub Pages에서도 별도 설정 없이 동작한다.
- 링크 미리보기(Open Graph 태그)와 하단 저작권 문구 넣기
- 패치 대응 도구 만들기
  - 영어 이름을 넣으면 identifier를 찾아 roster에 추가하는 명령
  - PokéAPI에 아직 없는 포켓몬이나 챔피언스에서 바뀐 수치를 적어 두는 보충 파일
- GitHub Actions 버전 올리기. 배포할 때 Node 20 지원 중단 경고가 나온다.
- 1:1 비교에서도 메가진화 포켓몬에는 스카프를 적용하지 않기
- 정보 창의 방어 상성에 특성(부유 등) 반영하기
- 데이터에 폼·지역 구분 필드 넣기. 지금은 이름 문자열과 key로만 구분한다.
